# FIKHAR Studio

> A premium personal portfolio focused on frontend development, creative coding, and interactive digital experiences.

FIKHAR Studio is a personal portfolio website built to showcase frontend projects, development journey, design principles, and selected digital experiences.

The website focuses on clean visual design, responsive layouts, subtle motion, and interactive experiences while keeping the implementation lightweight and maintainable.

---

## ✦ Features

- Responsive portfolio layout
- Custom loading experience
- Custom cursor interaction
- Animated hero section
- Featured projects showcase
- Project technology stack
- Live demo and source code links
- About section with principles and statistics
- Personal development journey timeline
- Contact section
- Animated footer
- GSAP-powered scroll animations
- Smooth scrolling with Lenis
- Interactive project previews
- Mobile-friendly layout

---

## 🛠 Tech Stack

### Frontend

- HTML
- JavaScript
- Vite
- Tailwind CSS

### Animation & Interaction

- GSAP
- ScrollTrigger
- Lenis

### Icons

- Lucide
